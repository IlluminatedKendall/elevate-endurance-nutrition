# Elevate Nutrition & Endurance Coaching

Source for **elevateendurancenutrition.com** — Lizzie's coaching site.

Hand-built static site (plain HTML + CSS, no build step), migrated from GoDaddy Websites + Marketing in Nov 2026. Hosted on GitHub Pages from the `main` branch.

| URL | File |
|---|---|
| `/` | `index.html` |
| `/about-me` | `about-me.html` |
